# STOCKKOLON26 개발 인계

개발 마감은 2026년 12월 12일(한국 시간)이다. 아래 목록은 2026년 11월 25일 로컬 작업 폴더 기준이다. 시세 최적화와 화면 정리는 커밋 `c815634`로 Render에 반영됐다. 프로필 사진 제거는 로컬 변경 사항이다.

기술 스택은 Python, Flask, Jinja, HTML·CSS·JavaScript다. 로컬 검증은 SQLite, 배포 환경은 PostgreSQL을 사용한다.

## 완료

- [x] 홈의 내 투자 현황과 다른 회원의 투자 현황에서 영어 장식 문구와 소개 문장을 제거했다. 제목, 투자 지표와 거래 내역 링크를 유지했다.
- [x] 홈·거래·뉴스·순위·설정·인증·운영 화면의 반복 문구와 하단 장식 설명을 정리했다. 입력 조건, 오류와 거래 확인 문구는 필요한 위치에 남겼다.
- [x] 휘장(시그니처·프레임)의 화면, API, 방문 기록, 지급·장착 처리, 시장 갱신·주문 연결, 이미지와 전용 테스트·문서를 제거했다. 신규 DB에는 관련 테이블을 생성하지 않는다.
- [x] 투자 요약 카드와 순위 화면의 장식 그라데이션을 단색으로 바꾸고, 시상대의 빛 효과와 트로피 애니메이션을 제거했다. 자산 비중 차트는 항목을 단색으로 구분한다.
- [x] ‘포트폴리오’를 ‘투자 현황’, ‘평가손익’을 ‘현재 손익’, ‘리더보드’를 ‘순위’로 바꾸는 등 화면 문구를 쉽게 정리했다.
- [x] 기존 시세 최적화 작업에서 주기적 갱신과 읽기 요청을 분리했다. 로컬에서 갱신 중에도 시세 API가 마지막으로 저장된 가격을 반환하는 것을 확인했다.
- [x] Python 테스트 91개, JavaScript 테스트 19개를 통과했다. 테스트용 PostgreSQL이 필요한 항목은 생략했다.
- [x] Flask에서 화면 경로 12개를 렌더링하고, 휘장 API 3개가 404를 반환하며 새 SQLite DB에 휘장 테이블이 생성되지 않는 것을 확인했다.

- [x] 프로필 사진 선택·업로드를 제거했다. 소속 동아리 로고를 표시하고, 로고가 없으면 기본 이미지를 표시한다. 기존 업로드 데이터는 DB에 남아 있다.
